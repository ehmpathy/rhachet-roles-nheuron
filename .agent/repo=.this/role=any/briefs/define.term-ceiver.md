# define.term-ceiver

## .what

ceiver = one who takes/receives

from latin **capere** ("to take"). the `-ceive` root appears in english only with prefixes (receive, perceive, deceive, conceive), but the bare form is useful as a domain term.

## .why

symmetric with **sender**:

| current | issue |
|---------|-------|
| sender / receiver | asymmetric — receiver has re- prefix |
| sender / recipient | asymmetric — different word structure |

| proposed | benefit |
|----------|---------|
| sender / ceiver | symmetric — both are [root]-er agent nouns |

## .usage

in mail/message domains:

```ts
mail.sender   // who sent
mail.ceiver   // who received
```

## .etymology

| word | latin | definition |
|------|-------|------------|
| capere | - | to take |
| receive | re-cipere | take back |
| perceive | per-cipere | take entirely |
| deceive | de-cipere | take away |
| conceive | con-cipere | take in |
| **ceiver** | capere + -er | one who takes (coined) |

## .note

this is a coined term for domain clarity. document and use consistently.
