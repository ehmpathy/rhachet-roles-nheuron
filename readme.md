# 🪼 rhachet-roles-nheuron

externalized brain roles and skills, via [rhachet](https://github.com/ehmpathy/rhachet)

## purpose

nheuron = neuron + externalized

this repo provides roles for externalized thought — memory that persists beyond sessions, patterns that compound over time, cognition that extends your reach.

## install

```sh
npm install rhachet-roles-nheuron
```

## roles

### 🫙 collector

- **scale**: intake-level, thought capture
- **focus**: gather thoughts from distributed sources — emails, texts, slacks, paper
- **maximizes**: no thought lost, all captured

### 🧵 connector

- **scale**: synthesis-level, thought linkage
- **focus**: weave new threads across old ones — find patterns, surface relations
- **maximizes**: emergent insight through connection

### 🔦 allocator

- **scale**: attention-level, priority direction
- **focus**: shine on where attention goes — what's next, todos, deadlines, responses
- **maximizes**: clarity on what matters now
