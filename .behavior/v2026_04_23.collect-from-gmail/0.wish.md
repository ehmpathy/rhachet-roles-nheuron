# Gmail API Setup for Email Polling

## Personal @gmail.com accounts

- Use OAuth 2.0 with user consent
- Create project in Google Cloud Console, enable Gmail API
- Configure OAuth consent screen as "External"
- Create OAuth 2.0 credentials (Desktop app type)
- **Limitation:** Apps in "Testing" mode have refresh tokens that expire after **7 days**
- To avoid weekly re-auth: must go through Google's app verification process

## Google Workspace (custom domain like ahbode.com)

### Option 1: Internal OAuth app
- Set OAuth consent screen to **"Internal"** (org-only)
- Refresh tokens **don't expire** after 7 days
- No Google verification needed
- User still consents once via browser

### Option 2: Service account with domain-wide delegation (best for automation)
- No user interaction needed
- Admin grants service account permission to impersonate users
- Can access any mailbox in the domain

**Setup steps:**
1. Create service account in Cloud Console
2. Enable domain-wide delegation on it
3. Google Workspace Admin → Security → API Controls → Domain-wide delegation
4. Add service account client ID + scopes
5. In code, impersonate target user:

```python
from google.oauth2 import service_account

creds = service_account.Credentials.from_service_account_file(
    'service-account.json',
    scopes=['https://www.googleapis.com/auth/gmail.readonly']
).with_subject('user@yourdomain.com')
```

## Useful scopes
- `https://www.googleapis.com/auth/gmail.readonly` — read-only
- `https://www.googleapis.com/auth/gmail.modify` — read + modify labels
