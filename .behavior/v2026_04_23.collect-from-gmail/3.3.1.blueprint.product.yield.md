domain.operations/gather/adapters/ses/auth/
├─ [+] getSesAuthAdapter
│  │  output: GatherAuthAdapter
│  │  .what = pure factory: ses auth adapter. genAuth is a no-op (iam is ambient), genAuthRefresh returns the profile creds

|---------|---------|

### infra dependency

the ses adapter needs aws + cloudflare infra provisioned before it can run against a real
mailbox. that infra is declared + provisioned via **declastruct-aws** (aws side) plus a
one-time manual cloudflare dns step — see the handoff:
`.agent/repo=.this/role=any/briefs/howto.provision-ses-email-infra.[handoff].md`.
primary address shape is a mail subdomain, e.g. `robot@mail.ehmpath.com` (test:
`robot@demo.ehmpathy.com`).

## amendment: eight declared operations no longer exist

⚠️ **read this before the filediff tree and the test-coverage matrix below.** both name eight
files that are absent from the repo. they are named here as *planned*, and the plan is kept
as approved — but a reader who searches for them will not find them, so the current truth is
stated here rather than left to a failed grep.

| named below | why it is absent |
|-------------|------------------|
| `getMailCacheKey` | superseded by `getCacheDir`. worse than surplus — it pasted the exid **raw** into a path, the exact defect the real write path guards against, so a dev who reached for the "canonical cache key" would have re-introduced it |
| `getSyncStatsCacheKey` | its declared consumer was `withLock(getAllMail, …)`, which was never built |
| `getIsRateLimitError`, `getIsNetworkTimeoutError`, `getIsTokenExpiredError` | their declared consumer was `withRetry(getAllMailFromGmail, …)`, which was never built |
| `getRecoverableErrorOutput` | the cli prints `error.message` instead |
| `getGmailOAuthUrl`, `getGmailTokensFromResponse` | the interactive oauth flow was never built; gmail authenticates via a service account. the token parser additionally encoded a **false** claim about google's contract (that `refresh_token` is always returned), locked in by green tests |

⚠️ **the deeper gap, which the absent files conceal:** this behavior shipped **without its
declared resilience layer** — no retry on gmail 429s, no lock around a concurrent sync — and
its verification passed regardless, because each orphaned leaf carried a green unit test. six
green test files stood in for a layer that was never wired.

the deletions were made from the ses behavior (`v2026_07_30.collect-from-ses`), which shares
this branch, and are recorded there as fulcrum **F7** and peer point **r11.4** — each with the
one command that restores it, should the council overturn them.

## summary

build the gatherer role for rhachet-roles-nheuron with two gmail gather skills:

1. **gather.auth** — oauth flow for gmail, stores tokens in keyrack os.secure
2. **gather.mail** — fetch and cache mail readonly, security obfuscation for sensitive content

architecture: run + adapter pattern enables future mechanisms (slack, phone) via same `--from` flag.

## glossary

| term | definition |
|------|------------|
| exid | external identifier — the immutable message id from gmail api; used as primary key for cache |
| ceiver | one who receives — symmetric shorthand for receiver, paired with sender (from latin capere "to take"); see brief define.term-ceiver.md |
| keyrack | credential storage abstraction in rhachet; manages encrypted secrets per environment |
| os.secure | keyrack storage backend that uses OS-level secure storage (keychain on macOS, secret-service on linux) |
| treestruct | tree-structured output format with unicode box-draw characters for hierarchical cli output |
| boop | nheuron mascot phrase that establishes brand presence in cli output |
| gen | ehmpathy verb: find-or-create (findsert) — one of three core verbs (get/set/gen) in ehmpathy domain operations. finds extant or creates if absent; always idempotent. see brief rule.require.get-set-gen-verbs.md |
| set | ehmpathy verb: mutate/upsert — one of three core verbs (get/set/gen) in ehmpathy domain operations. always idempotent (safe to retry). see brief rule.require.get-set-gen-verbs.md |
| get | ehmpathy verb: retrieve/compute — one of three core verbs (get/set/gen) in ehmpathy domain operations. pure retrieval, never mutates. see brief rule.require.get-set-gen-verbs.md |
| transformer | pure computation with no side effects — deterministic input→output functions. includes: parse, format, validate, decide. no i/o, testable without mocks. MUST NOT throw (throw = side effect); returns boolean or result type |
| communicator | raw i/o boundary operation — handles connection, auth, request/response with external systems (sdks, daos, filesystems). minimal business logic, just data transfer |
| orchestrator | composition of named operations — coordinates transformers and communicators into workflows. each line should read as narrative (what happens, not how). no inline decode-friction. may throw as part of control flow |
| guard | assertion that throws on condition — prefixed with `assert*`. NOT a transformer (throws = side effect). used for precondition checks that halt execution on failure |
| mechanism | the communication channel type — 'gmail' \| 'slack' \| 'phone'. identifies which adapter handles this communication. GatheredMailMechanism is the domain literal |
| repo | a mailbox identity — `{ mechanism: GatheredMailMechanism, address: string }`. every mail has a ceiver repo and sender repo. GatheredMailRepo is the domain literal |
| address | mechanism-specific identifier for a mailbox — for gmail: email address (vlad@gmail.com); for slack: workspace/channel (ehmpathy/channels=general). scoped under repo, not ambiguous |
| adapter | interface contract for origin-specific operations — allows polymorphic dispatch to different implementations (gmail, slack, phone) via same caller code. pure factory functions return adapter instances |
| outputStyle | format for cli output — 'tree' \| 'json'. determines how results are rendered to stdout |
| run | ehmpathy verb: execute skill entrypoint — established pattern for skill-level operations that compose adapters and orchestrators. see runGatherMail, runGatherAuth |
| skill | executable capability exposed by a role — shell entrypoint that invokes domain operations. gather.auth and gather.mail are skills |
| role | collection of skills + briefs that define a capability — gatherer role provides mail collection skills |
| gatherer | role that collects async communications from origins — this blueprint builds the gatherer role with gmail support |
| syncStats | sync progress and statistics — stores position in mailbox for incremental sync. `GatheredMailSyncStats` contains: `mailFoundUptil` (timestamp of most recent mail), `mailFoundQuant` (cached count), `mailSyncedQuant` (mails synced in this operation), `historyId` (gmail cursor for delta sync) |
| PaginationInput | pagination request from `pagination-fns` — range-based pagination: `{ range: { since?: T; until?: T; uptil?: T }; order: 'ASC' \| 'DESC'; limit: number }` where T is the range shape. output is `PaginationInput<T> \| null` (null when no more pages) |
| UniDateTime | universal datetime type from `uni-time` — represents timestamps consistently across timezones |

### journey acceptance test

a journey test exercises the complete user workflow across multiple timesteps.

uses `useThen`/`useWhen` for shared results across assertions. one assertion per `then` block.

```typescript
describe('gather.journey', () => {
  given('[case1] complete gmail collection journey', () => {
    when('[t0] initial state — not authenticated', () => {
      const result = useThen('cli executes', async () =>
        execCli(['gather.mail', '--from', 'gmail://test@gmail.com'])
      );
      then('stderr contains auth required error', () => {
        expect(result.stderr).toContain('not authenticated');
      });
      then('exit code is 2 (constraint)', () => {
        expect(result.exitCode).toBe(2);
      });
      then('output matches snapshot', () => {
        expect(result).toMatchSnapshot();
      });
    });

    when('[t1] first-time auth', () => {
      const result = useThen('cli executes', async () =>
        execCli(['gather.auth', '--from', 'gmail://test@gmail.com'])
      );
      then('stdout prompts for oauth', () => {
        expect(result.stdout).toContain('open browser');
      });
      then('output matches snapshot', () => {
        expect(result).toMatchSnapshot();
      });
    });

    when('[t2] auth completes', () => {
      const result = useThen('oauth flow completes', async () =>
        completeOAuthFlow()
      );
      then('stdout confirms token stored', () => {
        expect(result.stdout).toContain('authenticated');
      });
      then('exit code is 0 (success)', () => {
        expect(result.exitCode).toBe(0);
      });
      then('output matches snapshot', () => {
        expect(result).toMatchSnapshot();
      });
    });

    when('[t2.5] first mail sync without --since', () => {
      const result = useThen('cli executes', async () =>
        execCli(['gather.mail', '--from', 'gmail://test@gmail.com'])
      );
      then('stderr contains helpful error', () => {
        expect(result.stderr).toContain('--since required for first run');
      });
      then('exit code is 2 (constraint)', () => {
        expect(result.exitCode).toBe(2);
      });
      then('output matches snapshot', () => {
        expect(result).toMatchSnapshot();
      });
    });

    when('[t3] first mail sync — with --since', () => {
      const result = useThen('cli executes', async () =>
        execCli(['gather.mail', '--from', 'gmail://test@gmail.com', '--since', '2026-01-01'])
      );
      then('stdout contains synced count', () => {
        expect(result.stdout).toContain('synced');
      });
      then('exit code is 0 (success)', () => {
        expect(result.exitCode).toBe(0);
      });
      then('output matches snapshot', () => {
        expect(result).toMatchSnapshot();
      });
    });

    when('[t3.5] label-scoped sync', () => {
      const result = useThen('cli executes', async () =>
        execCli(['gather.mail', '--from', 'gmail://test@gmail.com/labels=work,urgent', '--since', 'sync'])
      );
      then('stdout shows label filter applied', () => {
        expect(result.stdout).toContain('labels: work, urgent');
      });
      then('exit code is 0 (success)', () => {
        expect(result.exitCode).toBe(0);
      });
      then('output matches snapshot', () => {
        expect(result).toMatchSnapshot();
      });
    });

    when('[t4] incremental sync — cache populated', () => {
      const result = useThen('cli executes', async () =>
        execCli(['gather.mail', '--from', 'gmail://test@gmail.com', '--since', 'sync'])
      );
      then('stdout shows new mail count', () => {
        expect(result.stdout).toContain('new mails');
      });
      then('exit code is 0 (success)', () => {
        expect(result.exitCode).toBe(0);
      });
      then('output matches snapshot', () => {
        expect(result).toMatchSnapshot();
      });
    });

    when('[t5] cache hit — no new mail', () => {
      const result = useThen('cli executes', async () =>
        execCli(['gather.mail', '--from', 'gmail://test@gmail.com', '--since', 'sync'])
      );
      then('stdout shows from cache', () => {
        expect(result.stdout).toContain('from cache');
      });
      then('stdout shows 0 new', () => {
        expect(result.stdout).toContain('0 new');
      });
      then('exit code is 0 (success)', () => {
        expect(result.exitCode).toBe(0);
      });
      then('output matches snapshot', () => {
        expect(result).toMatchSnapshot();
      });
    });

    when('[t6] security-sensitive mail', () => {
      const result = useThen('cli executes', async () =>
        execCli(['gather.mail', '--from', 'gmail://test@gmail.com', '--since', 'sync'])
      );
      then('stdout shows obfuscated content', () => {
        expect(result.stdout).toContain('[content obfuscated');
      });
      then('exit code is 0 (success)', () => {
        expect(result.exitCode).toBe(0);
      });
      then('output matches snapshot', () => {
        expect(result).toMatchSnapshot();
      });
    });

    when('[t7] token expired mid-journey', () => {
      const result = useThen('cli executes', async () =>

        expect(cacheState.files).toHaveLength(expectedCount);

      then('cache state matches snapshot', () => {
        expect(cacheState).toMatchSnapshot();
      });
    });
  });
});
```

## keyrack integration

add to `.agent/keyrack.yml`:

```yaml
env.test:
  - GATHER_GMAIL_CLIENT_ID      # google oauth client id
  - GATHER_GMAIL_CLIENT_SECRET  # google oauth client secret
```

user tokens stored in os.secure under pattern:
`GATHER_{mechanism}_TOKEN_{hashOf(address)}`

e.g., for gmail: `GATHER_GMAIL_TOKEN_{hashOf(vlad@gmail.com)}`
e.g., for slack: `GATHER_SLACK_TOKEN_{hashOf(ehmpathy)}`

## security considerations

1. **readonly scope only** — `gmail.readonly` prevents modifications
2. **token storage** — keyrack os.secure (age-encrypted)
3. **content obfuscation** — security-sensitive mails hidden
4. **no browser interaction** — fetch only, no click risk
5. **local cache** — mails never leave local machine
