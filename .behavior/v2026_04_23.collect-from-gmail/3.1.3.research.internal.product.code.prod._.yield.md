## pattern.3 = shell skill dispatch

### sources

1. [external] ehmpathy/rhachet-roles-bhuild/src/domain.roles/behaver/skills/init.behavior.sh — shell skill pattern

### claims

**[FACT]** shell skills dispatch to TypeScript via exec
> ```bash
> #!/usr/bin/env bash
> set -euo pipefail
> exec node -e "import('rhachet-roles-bhuild').then(m => m.cli.initBehavior())" -- "$@"
> ```
— source [1]

**[FACT]** shell header documents .what, .why, usage, options, guarantee
> ```bash
> ######################################################################
> # .what = initialize a .behavior directory for bhuild thoughtroute
> #
> # .why  = standardize the behavior-driven development thoughtroute
> #         by creation of a structured directory with:
> #           - wish definition (0.wish.md)
> #           ...
> #
> # usage:
> #   init.behavior.sh --name <behaviorname> [--dir <directory>]
> #
> # guarantee:
> #   - creates .behavior/ if not found
> #   - idempotent: safe to rerun
> #   - fail-fast on errors
> ######################################################################
> ```
— source [1]

### decision

**[REUSE]** shell skill dispatch pattern — apply same structure for gather.auth and gather.mail:
- shell wrapper with documented header
- exec dispatch to TypeScript implementation
- fail-fast via `set -euo pipefail`
