## the constraint

Gmail API OAuth requires interactive browser authentication:

1. user runs `gather.auth --from gmail`
2. browser opens, user consents to gmail access
3. callback returns tokens, stored locally
4. subsequent `gather.mail` calls use stored tokens

this flow **cannot be automated in CI** because:
- no way to automate browser consent
- no service account for personal gmail (only workspace domains)
- real credentials would risk security exposure
