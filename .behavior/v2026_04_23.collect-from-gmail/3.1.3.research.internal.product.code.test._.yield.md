## pattern.1 = jest configuration

### sources

1. [internal] jest.unit.config.ts — unit test configuration
2. [internal] jest.integration.config.ts — integration test configuration

### claims

**[FACT]** unit tests exclude integration and acceptance tests
> ```typescript
> testMatch: [
>   '**/*.test.ts',
>   '!**/*.acceptance.test.ts',
>   '!**/*.integration.test.ts',
>   '!**/.yalc/**',
> ],
> ```
— source [1]

**[FACT]** integration tests have dedicated config with slowtest reporter
> ```typescript
> reporters: [
>   ['default', { summaryThreshold: 0 }],
>   [
>     'test-fns/slowtest.reporter.jest',
>     {
>       slow: '10s',
>       output: '.slowtest/integration.report.json',
>     },
>   ],
> ],
> testMatch: ['**/*.integration.test.ts', '!**/.yalc/**', '!**/.scratch/**'],
> ```
— source [2]

### decision

**[REUSE]** jest configuration — infrastructure already exists, no changes needed

## pattern.3 = BDD test pattern (from briefs)

### sources

1. [loaded] howto.write-bdd.[lesson].md — BDD test pattern from mechanic briefs

### claims

**[FACT]** tests use given/when/then from test-fns
> ```typescript
> import { given, when, then, useBeforeAll } from 'test-fns';
>
> describe('featureName', () => {
>   given('[case1] description', () => {
>     const scene = useBeforeAll(async () => { return { entity: await createEntity() }; });
>     when('[t0] action', () => {
>       then('outcome', async () => { expect(await performAction()).toEqual(expectedValue); });
>     });
>   });
> });
> ```
— source [1]

**[FACT]** test labels use case/step notation
> - label given blocks with [caseN]
> - label when blocks with [tN], reset counter per given
— source [1]

### decision

**[REUSE]** BDD test pattern — apply test-fns pattern for all collector tests
