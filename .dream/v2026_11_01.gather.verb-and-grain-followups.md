## .the gap, precisely

1. **boolean verbs** — `getIsSecuritySensitive`, `getIsTokenExpired`, `getIsNoSuchBucketError`,
   `getIsScopeWholeMailbox`, `getIsHelpAsked`, `getStatusIsAnonymous` use `getIs*`; the
   sanctioned prefix is `is*` (r4 nitpick.3)
2. **guard verb** — `getDistinctAccountEmailsOrThrow` returns void; a `get*` promises a value
   (r4 nitpick.5)
3. **inline parse in communicators** — `getOneGatherAccessToken` and `getAllCachedMails` parse +
   validate json inline; extract `asGatherAccessTokenFromJson`, `asGatheredMailFromCacheJson`
   (r4 nitpick.1)
4. **domain literal as output** — `getAddressScope` returns `GatherAddressScope` rather than an
   inline shape (r4 nitpick.4)
5. **one large builder** — `getResourcesOfMail` declares ten resources inline; per-resource
   builders would let a later wish reuse one (r4 nitpick.6)
6. **ses live case unsnapped** — `gatherMail` `[case11]` asserts fields only; snap the tree +
   json with the volatile mailbox content masked (r9 nitpick.2)
7. ~~**gmail cases not hermetic**~~ — landed: `getEnvWithoutGmail()` clears
   `GMAIL_SERVICE_ACCOUNT_*` for every gmail status case in both acceptance suites (i004 r6)
8. ~~**ses `getAccessToken` throws on absent config**~~ — landed: both ses auth reads go through
   `getSesConfigOrNull`, clamped by `getSesAuthAdapter.test.ts` (i004 r10)
9. **inline http parse** — gmail `messages.list` + batch requests build and parse inline; a named
   request builder + `as*` response cast per call (i003 r4 nitpick.6)
10. **sync cursor read-modify-write** — two concurrent runs can regress the cursor; re-read the
    stats just before `upsertSyncStats` and keep the max, so a late write never moves it back
    (i003 r7 nitpick.3)
11. **dns wish refusals unclamped** — `resources.mail.dns.ts` refuses on absent cloudflare
    credentials and on empty `SES_DKIM_TOKENS`; an integration case with the env blanked would
    snap both messages (i004 r9 nitpick.7)
12. **raw literals typed as `GatheredMailRepo`** — `setGatheredMails` and peers build the repo as a
    plain object; `new GatheredMailRepo(...)` would run its schema (i004 r4 nitpick.8)

## .the shape of the fix

- 1, 2: `rhx sedreplace` per name, then a rename of each file (`mvsafe`)
- 3, 4, 5, 9: extract the named transformer, keep the communicator as read → cast
- 6: needs one live run to write the snapshot; do it on the first `TEST_LIVE=ses` run
- 7: one helper, applied to the five gmail not-configured cases
- 8: mirror the `getAuthStatus` guard, plus a unit case with no ses env
- 10: a monotonic write in `setMailsFromAdapter`, clamped by two interleaved runs

## .why it is not done in this round

each one ripples into callers, filenames, or acceptance snapshots, and the acceptance suite
cannot run locally without an sso session (`rule.always.fix-forward-under-scouts-honor`: safe,
but not clean). none ships a harm.
