## .the gap, precisely

1. **boolean verbs** — `getIsSecuritySensitive`, `getIsTokenExpired`, `getIsNoSuchBucketError`,
   `getIsScopeWholeMailbox`, `getIsHelpAsked`, `getStatusIsAnonymous` use `getIs*`; the
   sanctioned prefix is `is*` (r4 nitpick.3)
2. **guard verb** — `getDistinctAccountEmailsOrThrow` returns void; a `get*` promises a value
   (r4 nitpick.5)
3. **inline parse in communicators** — `getOneGatherAccessToken` and `getAllCachedMails` parse +
   validate json inline; extract `asGatherAccessTokenFromJson`, `asGatheredMailFromCacheJson`
   (r4 nitpick.1)
4. **domain literal as output** — `getAddressScope` returns `GatherAddressScope` rather than an
   inline shape (r4 nitpick.4)
5. **one large builder** — `getResourcesOfMail` declares ten resources inline; per-resource
   builders would let a later wish reuse one (r4 nitpick.6)
6. **inline arn strings** — `resources.mail.ts` builds s3 + iam arns by template; named
   `asS3BucketArn` / `asS3ObjectArn` / `asIamRootPrincipalArn` would match `asSesReceiptRuleArn`
   (r3 nitpick.2)
7. **unqualified error header** — `getExitCodeForError` prints `error: <message>`; the rule
   wants `✋ ConstraintError:` / `💥 MalfunctionError:` (r2 nitpick.1)
8. **ses live case unsnapped** — `gatherMail` `[case11]` asserts fields only; snap the tree +
   json with the volatile mailbox content masked (r9 nitpick.2)

## .the shape of the fix

- 1, 2: `rhx sedreplace` per name, then a rename of each file (`mvsafe`)
- 3, 4, 5, 6: extract the named transformer, keep the communicator as read → cast
- 7: change the two `setStderr` lines, then resnap every acceptance error snapshot
- 8: needs one live run to write the snapshot; do it on the first `TEST_LIVE=ses` run

## .why it is not done in this round

each one ripples into callers, filenames, or every acceptance snapshot, and the acceptance
suite cannot run locally without an sso session (`rule.always.fix-forward-under-scouts-honor`:
safe, but not clean). none ships a harm.
