# 🌙 dream: the verification guard's enroll lanes hand their brain a blank conversation path

kind: reseed · owner: ehmpathy/rhachet-roles-bhuild · caught 2026-11-24

## .the cue that fired

stone `5.3` i004, lane `r10:enroll-verif-snapshot-blemishes` malfunctioned. its brain refused
to review and asked for two things: the conversation path ("the sentence … has an empty
path") and which diff to read. `r9` and `r11` share the shape and reviewed past the gap.

## .the gap, precisely

`templates/5.3.verification.guard` (bhuild 0.24.0, lines ~284–294) passes each enroll lane
its prompt in single quotes:

```
-p '... read the prior peer-review conversation at $conversation to catch up on context.'
```

the single quotes keep `$conversation` from expansion, so the brain reads a blank or a literal
token where the path belongs. the prompt also says "review the diff" with no scope, where every
`rhx review` lane names `--diffs since-main`. a brain that asks rather than guesses meets a
malfunction, so the lane's outcome turns on the brain's temperament.

## .the shape of the fix

- double-quote the `-p` text (or close and reopen the single quotes around `$conversation`)
  so the path expands
- name the scope in the prompt: `the diff since origin/main`
- clamp with a guard-render test that asserts no enroll prompt holds a literal `$`

## .why it is not done in this round

the fix lives in bhuild. this route's guard is sealed (`route.mutate grant` is blocked), so a
local guard edit waits on the human's `rhx route.mutate grant allow`.
