# reason: sdk-logs@0.9.2

## package

## reason
declastruct-aws + declastruct-cloudflare provider factories take a ContextLogTrail from sdk-logs, whose LogMethods carries a `_` field a hand-rolled shape cannot satisfy. genLogMethods() is the sanctioned constructor, and it is what declastruct-aws own provision wishes use. needed by the provision wishes for the collect-from-ses mail stack.
